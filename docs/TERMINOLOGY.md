# Understanding the Report Metrics

To ensure transparency, the NARI system breaks down its evaluation into objective, measurable metrics. This glossary explains what these terms mean when you view a candidate's report.

### **Overall Match Score (0.0 - 10.0)**
This is not a flat average. It is a **confidence-weighted average** of the different agent scores. For example, if the SkillMatcher gives a candidate a 9/10 (with high confidence) but the CultureFit gives a 4/10 (with low confidence regarding their communication skills), the overall score mathematically accounts for both the score and the certainty of the agents.

### **Confidence (Percentage %)**
This is a critical explainability metric. It represents how "certain" the AI agents are about their evaluation based on the provided text.
- **High Confidence (> 85%)**: The resume was clear, well-structured, quantifiable, and mapped directly to the Job Description parameters.
- **Low Confidence (< 60%)**: Suggests the resume might be missing key info, had formatting that occluded timelines, or the provided Job Description was too vague to score against accurately. 
*Note: If confidence is low, the pipeline will flag the candidate for manual human review.*

### **Bias Risk Level (LOW / MEDIUM / HIGH)**
This is NARI's proactive alert system for ethical AI hiring.
- **LOW**: No indicators of bias or proxy discrimination were found in the resume.
- **HIGH**: The system detected a pattern where a candidate might be being unfairly scored based on non-merit factors (e.g., geographic location bias, or graduation years being used implicitly against them).

### **Hiring Recommendation**
The final executive verdict generated by the Reporting Agent.
- **STRONG YES**: All three trinity agents scored highly with concrete evidence.
- **YES**: Solid match, meets the core competencies cleanly.
- **MAYBE**: The system identified a conflict (e.g., exceptional technical skills, but lacking the required leadership experience). The report will include highly targeted interview questions to investigate this gap.
- **NO / STRONG NO**: Fundamental requirements specified in the Job Description are completely absent.
